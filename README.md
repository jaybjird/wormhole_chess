# Wormhole Chess

A Flutter implementation of Wormhole Chess - a unique chess variant where pieces can teleport through wormholes on the board.

## About

Wormhole Chess is an innovative chess variant that adds teleportation mechanics to the traditional game. Pieces can move through wormholes, creating new strategic possibilities and exciting gameplay.

## Features

- 🎮 Full chess gameplay with standard rules
- 🌀 Wormhole mechanics for piece teleportation
- 📱 Cross-platform support (iOS, Android, Web, Desktop)
- 🎨 Beautiful and intuitive UI
- ⚡ Smooth animations and interactions
- 🎯 **Deterministic Custom Placement**: Players dictate the starting state of the board through dynamic initial piece placements (e.g., King-dependent starting arrays)
- 🌐 **Asynchronous Multiplayer**: Cloud-synced matches allowing for shareable deep links and offline-first local resiliency
